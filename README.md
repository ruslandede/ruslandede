## What I Do

**Core**
- **Business Analysis:** Elicit requirements, identify problems, and define scope with stakeholders.
- **System Analysis:** Translate requirements into functional specifications, system workflows, and process flows.
- **Documentation:** BRD, FSD, TSD, BPMN process flows, and system documentation.

**Supporting**
- **QA & Testing:** Test scenarios and test cases, manual testing, defect tracking, and UAT coordination.
- **UI/UX:** User flows, wireframes, mockups, and prototypes (Figma).
- **Data Analytics:** Reports and dashboards for data-driven decisions (Excel, Power BI).
- **Project Coordination:** Timelines, stakeholder alignment, and delivery support.
